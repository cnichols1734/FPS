# Urban Arena FPS

Unity **6.5 (6000.5.5f1)** · **URP Forward+** · M1 Pro tuned · zero paid assets.

## Open the project

1. Quit the Unity tutorial window if it’s still open.
2. Unity Hub → **Projects** → **Open** → select this folder:  
   `/Users/christophernichols/FPS Shooter`
3. Open scene: `Assets/_Project/Scenes/Arena.unity`
4. Press Play.

## Controls

| Action | Keyboard / Mouse | DualSense |
|--------|------------------|-----------|
| Move | WASD | Left stick |
| Look | Mouse | Right stick |
| Fire | LMB | R2 |
| ADS | RMB | L2 |
| Reload | R | Square |
| Sprint | Shift | L3 |
| Crouch | C / Ctrl | Circle |
| Jump | Space | X |
| AR / Pistol | 1 / 2 | D-pad up / down |
| Capture strip | F8 | — |

DualSense rumble + lightbar require **USB-C** on macOS (Bluetooth input works; haptics do not).
